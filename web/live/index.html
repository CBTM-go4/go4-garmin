How it works

Open this page on the phone, tap Start live run, then allow location access. For automatic heart rate, connect a Bluetooth HR strap or a Garmin watch broadcasting HR to the phone.

The page sends telemetry to the Pi every few seconds. I can coach off the live feed once it is connected.
